How to start

From zero to results

Step 1

Install AutoClaw

Open OpenClaw.app or run: npm i -g openclaw && openclaw — 2 minutes, done.

Step 2

Quick Start → choose AI model (free or API key) → approve permissions. Gateway starts automatically.

From ClawHub: web search, email, data analysis, design — one command each. Try: "Read my last 5 emails".

Set it to check email every 30 min, review calendar, send briefing — without you asking.
